One line per bug that was fixed, by screen: what the user saw, why, where the code is, how to see
it again, status. **A bug reported as fixed before: look it up here first**, then check whether
the case is the same one (a regression) or a new variant. Every fix gets a line here in the same
step as the fix (status: built / checked by script / confirmed by the user, with the date).

Code: `src\lib.rs` unless named. Saves: Glory_v3 (single player, Dortmund), tes / tes2 (network,
Ajax host + PSV client; tes2 = 9.9.25 before Real Madrid v Ajax).
